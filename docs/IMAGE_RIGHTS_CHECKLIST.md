# Catalog and store image rights checklist

Use this checklist before any photograph, logo, illustration, screenshot, or producer asset appears publicly.

## Required record for each asset

- [ ] Asset filename or storage path recorded
- [ ] Cheese, creamery, person, or screen represented
- [ ] Source URL or original photographer recorded
- [ ] Rights holder identified
- [ ] Permission basis selected: created by The Curd Nerd / commissioned / written permission / valid license
- [ ] License terms or written permission saved outside the public repository
- [ ] Required attribution recorded and displayed where necessary
- [ ] Permission covers mobile apps, website, social media, and store marketing
- [ ] Permission covers cropping, resizing, and color correction
- [ ] Any recognizable person supplied an appropriate release
- [ ] Producer trademarks are used accurately and without implying endorsement
- [ ] No stock watermark, embedded metadata concern, or prohibited license restriction remains
- [ ] Final image reviewed for private information, unsafe content, and misleading presentation

## App Store and Google Play screenshots

- Use test accounts and representative content only.
- Do not expose real email addresses, private tasting notes, precise personal information, or moderation records.
- Obtain permission before featuring a tester’s name, handle, avatar, tasting, or photograph.
- Keep screenshots consistent with the version being submitted.
- Record the build number and capture date with the source files.

## Catalog photography

Real producer or retailer photography should not be copied merely because it is publicly viewable. Obtain permission or use photography created for By the Whey. Admin approval in the app verifies content suitability; it does not establish copyright permission.
